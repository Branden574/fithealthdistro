# SiteContent

A worked example of the admin page where the owner edits the storefront's text, built only from the components.

1. Page head: the title, "Preview site", and the page's one `primary` Button, which counts what it will publish.
2. A `warning` Alert while there are unpublished changes, with Discard. A `success` Alert when there are none.
3. Tabs for the pages of the site, with a count on the page that has unpublished changes.
4. One Panel per section of the page, holding its ContentFields two to a row.

Change the headline to see Unpublished, publish it to see Edited, and press Restore original to put the shipped text back. The slots, their keys and their original text are listed in `site-copy.md`.
