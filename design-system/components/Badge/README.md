# Badge

One or two words of status. The word carries the meaning; the tone backs it up.

## Tones

| Tone | Means | Examples |
| --- | --- | --- |
| `accent` | New or promoted | New, Featured |
| `success` | Good, available, done | In stock, Replied |
| `warning` | Needs attention soon | Low stock |
| `danger` | Blocked or gone | Out of stock |
| `info` | Not public yet | Draft |
| `neutral` (default) | Plain facts | Hidden, Read, a product name |
| `solid` | Emphasis with no status | Admin |

The status tones are a soft fill with the status color as text and edge. `accent` is orange with ink text and an `accent-ink` edge.

## You provide

The word. Add `dot` for a live state (stock, an unread inquiry) or `icon` for a glyph.

## Don't

- A badge is never pressed. A filter is a Chip.
- Never rely on the color alone, and never use a tone as decoration.
- No more than two badges on one product card.
