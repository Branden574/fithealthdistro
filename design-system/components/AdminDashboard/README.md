# AdminDashboard

A worked example of the admin's home page, built only from the components.

The Sidebar takes the first column at `sidebar` width; the page sits on `bg-subtle` with `space-8` padding and a `space-6` gap between blocks.

1. Page head: an eyebrow, the title in `display-md`, and the page's actions with one `primary`.
2. Four StatCards: active clients, client retention (the highlighted one), new inquiries, products live.
3. A Panel with the retention BarChart, beside the latest InquiryCard.
4. A flush Panel with Tabs and the products DataTable, where a Switch shows or hides each product and the trash button asks before removing.

Every number and name on it is sample data.
