# Wordmark

The company name set in Big Shoulders 900. It stands in for a logo until one exists.

## You provide

Nothing is required. `size` sets the font size: 24 in the NavBar, 20 in the Sidebar, 40 in the footer. `stacked` breaks the name over two lines for narrow columns. `short` gives "FHD" for spots too tight for the name, such as the monogram tile.

It takes the current text color, so it is `ink` on light and near-white on dark with no extra work.

## Files

Where the font cannot load (a favicon, an email, a social image) use the outlined SVGs in `assets/Logos`.

## Don't

- Don't set the wordmark in volt, and don't stretch it, outline it or add a shadow.
- Don't put anything within one cap height of it.
- When a real logo arrives, pass it to `brand` on the NavBar and Sidebar and replace the files in `assets/Logos`.
