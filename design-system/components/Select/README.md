# Select

A labelled native select, styled to match TextField.

It opens the platform's own menu, so it works with a keyboard, a screen reader and a phone without extra code.

## You provide

`label`, `options` (`value` and `label` each) and the value. `placeholder` shows while nothing is chosen ("Choose a category"). `hint` and `error` behave as on TextField.

## Use it for

- A product's category in the admin.
- "I am interested in" on the contact form.
- Any single choice from more than five options, or where space is tight.

## Don't

- Two to five options that filter a list are Chips.
- An on/off choice is a Switch or a Checkbox.
