# Logos

Placeholder marks. No logo was supplied, so these are the company name set in Big Shoulders 900 and converted to outlines; they need no font to display. Replace them, keeping the file names, when a real logo exists.

- `fhd-wordmark-ink.svg`: the one-line wordmark in ink `#0b0c0a`, for light grounds.
- `fhd-wordmark-white.svg`: the same in white `#ffffff`, for dark grounds and photos.
- `fhd-wordmark-stacked-ink.svg` and `fhd-wordmark-stacked-white.svg`: two lines, for narrow columns and the footer.
- `fhd-monogram-volt.svg`: FHD in ink on a volt `#c5f82a` tile with an ink edge. The favicon and the default avatar; it works on light and dark grounds.
- `fhd-monogram-ink.svg`: FHD in volt on an ink tile, for light grounds where the volt tile is too loud.

Each file has fixed inks; an `<img>` cannot recolor it. In a page that has the fonts, use the Wordmark component, which follows the theme.

Keep one cap height of clear space around a wordmark. Nothing smaller than 16px tall.
