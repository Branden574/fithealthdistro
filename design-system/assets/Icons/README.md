# Icons

67 glyphs from Phosphor Icons, Bold weight (MIT, see `licenses/Phosphor-MIT.txt`), copied unchanged except for the fill, which is fixed to ink `#0b0c0a` so the files show in an `<img>`. Each is drawn on a 256 grid.

In a page, use the Icon component, or inline the path with `fill="currentColor"`, so the glyph follows the theme. Use these files where neither is possible, and on light grounds only.

`lockers` stands for vending machines (Phosphor has no vending machine; this is the closest cabinet), `jar-label` for supplements and `drop` for drinks.

- Catalog: `lockers`, `jar-label`, `drop`, `package`, `storefront`, `shopping-cart-simple`, `tag`, `truck`, `barbell`, `pill`, `lightning`.
- Admin: `squares-four`, `chart-bar`, `chart-line-up`, `users-three`, `user`, `tray`, `envelope-simple`, `chat-text`, `phone`, `map-pin`, `buildings`, `gear`, `sign-out`, `lock-simple`, `shield-check`, `bell`, `text-aa`.
- Actions: `plus`, `minus`, `x`, `check`, `trash`, `pencil-simple`, `magnifying-glass`, `funnel-simple`, `eye`, `eye-slash`, `copy-simple`, `upload-simple`, `download-simple`, `arrows-clockwise`, `dots-three`, `list`, `link-simple`.
- Direction: `caret-down`, `caret-up`, `caret-left`, `caret-right`, `caret-up-down`, `arrow-right`, `arrow-left`, `arrow-up-right`, `trend-up`, `trend-down`.
- Status: `warning`, `warning-circle`, `info`, `check-circle`, `x-circle`, `clock`, `calendar-blank`, `image`, `star`, `currency-dollar`, `receipt`, `question`.
